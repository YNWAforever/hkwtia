# Translation review: proper nouns in the institutional history record

`content/milestones.ts` now has Chinese and English text for all 61 entries in WTIA's
history record (2001–2025). The prose itself does not need line-by-line review —
asking anyone to read 7,000+ words of translated history to catch small phrasing
differences would stall the project for little benefit. What *does* need review is
narrower and more important: every proper noun below — an organisation's name, an
award title, a government programme, or a person's name — was rendered by a
non-native process and could contain an error that would be embarrassing in a
published, official association history (a wrong award name, or worse, a wrong
person's name). Please go through each row and mark whether the rendering is
correct, using your own records or the person/organisation's own preferred usage
where you have it. Rows marked "reused from source" carry the least risk, since
they were already given bilingually somewhere in the archive rather than translated
fresh — but every row should still get a check.
