## Known gaps

- On Windows, the default unbounded Vitest worker tree did not terminate reliably. The complete bounded-worker suite covers the same configured file set and passed with a terminal exit-0 summary; four independent shards also passed.
- Hosted stale/error states were not injected because the isolated Preview role
  is intentionally read-only and the agent kill switches remain enabled.
  Deterministic unit coverage passed for stale, empty, unavailable, and
  repository-error privacy behavior without mutating hosted data.
- Live-provider results are intentionally absent; deterministic mocks are the
  only model path used in this evidence.
