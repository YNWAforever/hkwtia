# WTIA design system — "Signal & Record"

Status: in use on the public site from branch `feat/award-grade-experience-20261005`.
Presentation authority stays where the WiseTech design-fidelity programme put it (the donor
port), and this file describes the layer added on top of it. Every rule here is CSS that ships
today; nothing below is a proposal. Contrast figures are computed with the WCAG formula, not
estimated.

## 1. Direction

**Signal & Record.** WTIA began as the *wireless* association (2001) and is now an AI+
industry platform. The visual language uses that history literally:

- **Signal**: transmission arcs, receiving nodes and connecting lines. They are drawn only where
  they explain a relationship: the route finder joins an audience to the pages that serve it,
  and a page hero's mark varies with the page.
- **Record**: proof comes from the archive, never from invented numbers. Open-now falls back to
  the latest completed event, impact figures carry their definition and date, and every partner
  shown is a published record.

Three directions were compared before choosing this one:

| Direction | Credibility | Member conversion | Bilingual type | Originality | Performance | Maintenance |
|---|---|---|---|---|---|---|
| **A. Signal & Record** (chosen) | High: builds on the real archive | High: the route finder ends in real pages | Designed for both scripts | Motif is WTIA's own history | CSS/SVG only, 0 KB JS | One stylesheet |
| B. Archive-first timeline | Very high | Low: the past is not a next step | Good | Medium | Image-heavy | Needs curated assets |
| C. Dark "AI" showcase with gradients and particles | Low: generic | Medium | Weak for Han text | Low: template look | Costly | Fragile |

Rule: the light accent blues never carry text on white. `tests/e2e/experience-contrast.spec.ts`
measures the real cascade in Chromium, and it is shown red without the fix.

### Type

| Role | Latin | Han (zh-HK) | Size floor |
|---|---|---|---|
| Display / H1–H2 | `--font-serif` (Iowan / Palatino), −0.045em | `--font-display-zh` (PingFang TC / Noto Sans TC / Microsoft JhengHei), weight 600, tracking 0 | clamp per section |
| Card titles | serif 18–22px | CJK sans 600 | 18px |
| Running copy | `--font-sans` | same stack | **14px**, line-height 1.6 |
| Labels, metadata, form labels | sans 700–800 | | **12px** |
| Uppercase micro-labels (eyebrow, index) | sans 800, tracking .12–.2em | | **11px** |

- Han headings use `word-break: keep-all` plus `overflow-wrap: anywhere`. Spaces and punctuation
  are the preferred breaks, and a long unspaced heading still cannot overflow 320px. The zh
  hero now breaks 「香港如何引領 ／ AI+ 時代？」 instead of 「香港如何引 ／ 領…」.
- `text-wrap: balance` on headings and `text-wrap: pretty` on paragraphs.
- Long tokens (URLs, slugs) wrap anywhere inside `main`, so text is never clipped at 320px.

### Space, grid, breakpoints

- The shell is `min(1440px, 100% − 80px)`, or `100% − 32px` on phones (the 16px gutter).
- Section rhythm comes from the donor: `padding-block: clamp(84px, 8.5vw, 132px)`.
- Breakpoints are the donor's **max-width** set: `1320`, `1120`, `820` and `520`px. The route
  finder stacks at 1120; 820 is single column and the mobile navigation sheet.
- Page heroes: `min-height: clamp(420px, 58vh, 560px)` on desktop, content height on phones.

### Radius, elevation

- Radius: 10px (controls), 12px (options and destinations), 14px (cards), 18px (feature panels).
- Elevation: borders before shadows. The only shadow in this layer marks a *selected* route
  option: `0 18px 44px rgba(15,76,129,.2)`.

### Motion

| Token | Value | Use |
|---|---|---|
| `--xp-ease-out` | `cubic-bezier(.22,1,.36,1)` | All entrances |
| `--xp-dur-ui` | 180ms | Hover, selection, focus feedback |
| `--xp-dur-draw` | 620ms | A route branch drawing to its node |

Motion is only used to explain change: the route redraws when you pick an audience, and the
hero signal line draws once. Nothing loops, nothing hijacks scroll, nothing gates content.
Every animation is declared inside `@media (prefers-reduced-motion: no-preference)`, and the
global reduce rule in `app/globals.css` also applies.

## 4. Components

| Component | Where | Contract |
|---|---|---|
| **Route finder** (signature) | `components/home/pathways.tsx` | Native radio group plus CSS `:has()`. Zero JS. Arrow keys move between audiences. Every destination is a `publicRoutes` member (tested). Without `:has()`, all routes show stacked. |
| **Signal mark** | `components/wt/page-hero.tsx` | Inline SVG on heroes without a photo. Seeded by the title, so it is deterministic and SSR-safe. `aria-hidden`. |
| **Auth shell** | `components/auth/auth-shell.tsx` | Member and staff sign-in frame. The form comes first on phones. The explainer states only what the code guarantees (emailed link, continuation back to `next`). |
| **Open-now record** | `components/home/open-now.tsx` | Shown only when the open list read succeeded empty. Read with `status: "past"`, so it can never claim to be open. |
| Buttons | donor `.button`, `.button-dark`, `.button-light`, `.text-link` | Minimum height 44px (48px for the route primary). Arrow glyph `↗` is `aria-hidden`. |
| Forms | `.directory-search`, `.directory-actions` | Visible labels on every control. Each facet row has its own submit. 48px controls. |
| Cards | donor families | Light cards inside ink sections set their own ink heading colour (the open-events fix). |
| Tables | shadcn (admin) | Unchanged in this pass. |
| Images | own-origin only (`img-src 'self'`) | Archive photography with real alt text. No generated people, no stock. |
| Focus | `outline: 3px solid var(--wt-focus)`, offset 2–3px | Visible on every control, including visually hidden radios (drawn on their label). |
| Error / empty | `HonestEmpty`, `role="alert"` on sign-in errors | Never a fabricated record. A failed read degrades to the honest state. |

## 5. Do not

- Purple–blue gradients, glass panels, particle backgrounds, or the same fade-in on every section.
- Numbers without a definition and a date. Testimonials, awards or partners that are not on record.
- Text below the floors above. Light accent blues as text on white.
- New animation dependencies. The signature interaction is CSS.
