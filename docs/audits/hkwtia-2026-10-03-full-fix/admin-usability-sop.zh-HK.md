# 後台列表與覆核操作（T15）

## 每日操作

1. 用自己的職員帳戶登入，從今日工作或工作台搜尋進入案件。列表預設 50 筆；會員搜尋維持既有最多 50 筆，草稿／收件匣最多 100 筆。套用篩選後再進入下一頁，不能把目前頁面的選取當成全部結果。
2. 待審批表格在手機上可橫向捲動。用 Tab 聚焦有邊框的表格，再以方向鍵捲動；查看摘要、資料版本及決定按鈕。會籍計劃採用既有中英文名稱。
3. AI 覆核頁用「覆核狀態」篩選。到期時間須含時區，例如 `2026-10-31T17:00:00+08:00`；留空代表不限到期時間。模型、預算或 worker 未核實時，按既有人工流程處理。
4. 查看現行資料及最後正文，記錄覆核。核准草稿不會入會、收款、退款、送出或發布；另到原有工作流程完成已獲批准的操作。
5. 手機選單可用 Enter 開啟、Tab／Shift-Tab 移動、Esc 關閉；焦點返回原按鈕。共用電腦需切換自己的身份，不能把上一個職員的工作畫面留給會員。
6. unknown provider／付款／訊息結果先對帳，不換 key、盲目重試或等 TTL 當作退款。

## 效能紀錄

- 本機 PostgreSQL 與瀏覽器結果僅屬實驗室證據，不能稱為香港／新加坡或公開 RUM。
- 冷載入證據只清除瀏覽器快取，沒有清空 DB／app 快取。分別記 TTFB、DNS／TLS、傳輸大小及可操作時間；不要拿工具總等候時間判定 DB 慢。
- 嚴重／關鍵 axe 為 0 是自動最低門檻。真人 screen reader 及 3–5 位職員案件任務、兩星期人工基線及一星期試點仍須負責人完成。
