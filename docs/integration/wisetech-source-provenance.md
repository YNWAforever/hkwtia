## Evidence legend

| Label/state | Permitted claim |
|---|---|
| `hkwtia-repository` | The current repository contains the named route, redirect, action, typed owner or asset. |
| `site-v13-design-doc` | A supplied design document proposes the named pattern/route/category. It does not prove the Site source implements it. |
| `master-plan` | The integration plan requires the named outcome or boundary. |
| `site-v13-source` | The transferred, hash-verified Site source directly proves the claim. No current manifest entry uses this label. |
| Unavailable source archive | Site identity is known, but file-level claims and complete parity are prohibited. |

Evidence precedence is not a content overwrite rule. Repository evidence determines current runtime/data ownership; design documents may guide presentation; the master plan defines integration outcomes; a future source archive can prove donor implementation details but cannot replace hkwtia business authorities.
